////////////////////////////////////////////////////////////////////////////////
// Server: call rate test - answers a short call without media
//
// Counterpart of Perf_cps_client.
//
// Answers every call at once and waits for the BYE of the client. No RTP.
//
// Over UDP the 200 OK is sent again until the ACK comes, and an INVITE or a BYE
// that comes again is answered as before (;retrans, RFC 3261 timers with -t1 and
// -t2), so a SIP message lost under load makes a late call, not a failed one.
//
// SIP Messages
//  <--- INVITE ;retrans
//  ---> 100 Trying
//  ---> 180 Ringing
//  ---> 200 OK ;retrans (G.711 PCMU, telephone-event)
//  <--- ACK
//  <--- BYE ;retrans
//  ---> 200 OK
////////////////////////////////////////////////////////////////////////////////
