////////////////////////////////////////////////////////////////////////////////
// Client: call rate test - a short call without media
//
// Counterpart of Perf_cps_server.
//
// Measures how many calls a second the two machines can set up and end. No RTP is
// sent, so only the SIP signalling counts. test/capacity.py sets the hold time;
// the calls at a time are the call rate times the hold time.
//
// Over UDP the INVITE and the BYE are sent again until they are answered and a
// 200 OK that comes again gets the ACK again (;retrans, RFC 3261 timers with -t1
// and -t2), so a SIP message lost under load makes a late call, not a failed one;
// the run report counts the copies (sip.retransmitted, sip.repeatsReceived).
//
// SIP Messages
//  ---> INVITE ;retrans (G.711 PCMU, telephone-event)
//  <--- 100 Trying (optional)
//  <--- 180 Ringing
//  <--- 200 OK ;retrans
//  ---> ACK
//  ---- hold (cmd_Pause)
//  ---> BYE ;retrans
//  <--- 200 OK
////////////////////////////////////////////////////////////////////////////////

---------->;retrans
INVITE sip:[toUsername]@[remote_ip]:[remote_port] SIP/2.0
Via: SIP/2.0/[transport] [local_ip]:[local_port];branch=[branch]
From: <sip:[fromUsername]@[local_ip]:[local_port]>;tag=[call_number]
To: <sip:[toUsername]@[remote_ip]:[remote_port]>
Call-ID: [call_number].[run_tag]@[local_ip]
CSeq: [cseq+1] INVITE
Max-Forwards: 70
Contact: <sip:[fromUsername]@[local_ip]:[local_port];transport=[transport]>
User-Agent: SIPInspector_v_[ver]
Content-Type: application/sdp
Content-Length: [len]

v=0
o=111 843670094 843670094 IN [IP_ver] [local_ip_sdp]
s=-

a=rtpmap:0 PCMU/8000

a=fmtp:101 0-15
